# Orienta — Путь Героя

Игровой маршрут профориентации: пять ситуаций и четыре архетипа, гайд персонажа, пять этапов курса и Профкарта Героя. Сохранена существующая визуальная система: тёмный фон, золотые и фиолетовые акценты, карта пути и иллюстрации персонажей.

## Локальный запуск

Нужен Node.js 24.

~~~sh
npm install
npm run dev
~~~

Перед первым запуском скрипт сохраняет 38 исходных PNG из ссылок проекта в public/images. Повторный запуск использует локальную копию. Если хостинг изображений недоступен, npm run assets нужно повторить после восстановления доступа. Исходные URL записаны в data/assets.json; новые иллюстрации не генерировались.

## Проверки и сборка

~~~sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
~~~

npm test проверяет миграцию, ограничения, восстановление, этапы, резервные копии и профкарту. Браузерный сценарий проверяет полный маршрут, перезагрузку, таймер, импорт, сброс и ошибки хранилища. Свидетельства и снимки: output/playwright. GitHub Actions сохраняет output, dist и разрешённый package-lock.json как артефакт orienta-verification.

Готовая статическая сборка — dist. VITE_BASE_PATH по умолчанию равен ./ для размещения как в корне домена, так и в подкаталоге. Выбор хостинга и публикация в эту работу не входят.

## Ответы и сохранение

Версия данных — 3. Ответы и незавершённый тест хранятся в текущем браузере. Принимаются резервные копии версий 2 и 3; недостающие новые задания добавляются к прежним ответам. В хабе можно скачать или загрузить резервную копию JSON. Импорт сначала предлагает подтверждение и скачивает текущий прогресс. Сброс требует подтверждения; повторный тест сохраняет ответы курса, полное удаление сбрасывает весь маршрут.

Старый игровой архетип и ранее сохранённый вывод переносятся. Старые флаги трёх несвязанных модулей не считаются прохождением новых заданий без самих ответов. При повреждённом JSON исходная строка сохраняется в appState_ru_recovery, если хранилище доступно.

Облачная синхронизация и автоматическая запись в Google Sheets в этой версии не включены. Старый no-cors запрос не позволял подтвердить сохранение, а прежнее облачное поле не содержало ответов курса. Личные кабинеты и общая база требуют отдельного решения.

## Профкарта и ИИ

Основная профкарта собирается из ответов всех пяти этапов: выбранные профессии, самоанализ, ценности, три будущих подарка, навыки, работа мечты, профессиональные интересы, мотиваторы и план профессиональной пробы. Она доступна без внешнего ИИ; её можно скачать текстом или распечатать в PDF.

Дополнительный ИИ-разбор появляется только при заданном VITE_GOOGLE_SCRIPT_URL из .env.example. Пользователь запускает запрос явно. Сервер должен принять POST text/plain с JSON { action: "generate_ai", prompt: "..." } и вернуть JSON { text: "..." }. Все секреты, доступ к провайдеру, CORS, ограничения запросов и правила обработки данных остаются на сервере. Реальный сервер и провайдер в репозитории не настроены и не проверены. Ошибка или тайм-аут не подменяются готовым «ИИ-выводом».

## Что нужно согласовать перед запуском

См. docs/launch-decisions.md. Ветка и PR предназначены для проверки; слияние и развёртывание отдельно не выполняются.

## Пятиэтапная программа

Задания сопоставлены с подробными авторскими страницами Notion. XP, ранги за XP и «Формула» убраны по позднему авторскому решению. Два итоговых опросника включают 12 утверждений интересов (0–2, по два на направление) и 10 вопросов мотивации с исходными весами по 12 шкалам. Суммы считаются из ответов; равенство на границе топ-2 и топ-3 показывается явно. Валидированная диагностика не заявляется.

Для пяти этапов предусмотрены реальные видео и WebVTT-субтитры через VITE_LESSON_N_VIDEO / VITE_LESSON_N_CAPTIONS. Пока адреса пусты, показаны инструкции. Недельный ритм описан в программе, календарное открытие уроков пока не согласовано: текущий кандидат открывает следующий этап после завершения предыдущего.
