# Orienta — Путь Героя

Игровой маршрут профориентации: пять ситуаций и четыре архетипа, гайд персонажа, три этапа курса и итоговая профкарта. Сохранена существующая визуальная система: тёмный фон, золотые и фиолетовые акценты, карта пути и иллюстрации персонажей.

## Локальный запуск

Нужен Node.js 24.

~~~sh
npm install
npm run dev
~~~

Перед первым запуском скрипт сохраняет 38 исходных PNG из ссылок проекта в public/images. Повторный запуск использует локальную копию. Если хостинг изображений недоступен, npm run assets нужно повторить после восстановления доступа. Исходные URL записаны в data/assets.json; новые иллюстрации не генерировались.

## Проверки и сборка

~~~sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
~~~

npm test проверяет миграцию, ограничения, восстановление, этапы, резервные копии и профкарту. Браузерный сценарий проверяет полный маршрут, перезагрузку, таймер, импорт, сброс и ошибки хранилища. Свидетельства и снимки: output/playwright. GitHub Actions сохраняет output, dist и разрешённый package-lock.json как артефакт orienta-verification.

Готовая статическая сборка — dist. VITE_BASE_PATH по умолчанию равен ./ для размещения как в корне домена, так и в подкаталоге. Выбор хостинга и публикация в эту работу не входят.

## Ответы и сохранение

Версия данных — 2. Ответы и незавершённый тест хранятся в текущем браузере. В хабе можно скачать или загрузить резервную копию JSON. Импорт сначала предлагает подтверждение и скачивает текущий прогресс. Сброс требует подтверждения; повторный тест сохраняет ответы курса, полное удаление сбрасывает весь маршрут.

Старый игровой архетип и ранее сохранённый вывод переносятся. Старые флаги трёх несвязанных модулей не считаются прохождением новых заданий без самих ответов. При повреждённом JSON исходная строка сохраняется в appState_ru_recovery, если хранилище доступно.

Облачная синхронизация и автоматическая запись в Google Sheets в этой версии не включены. Старый no-cors запрос не позволял подтвердить сохранение, а прежнее облачное поле не содержало ответов курса. Личные кабинеты и общая база требуют отдельного решения.

## Профкарта и ИИ

Основная профкарта собирается детерминированно из ответов: интересы, ценности, самоанализ, подход к задачам, ситуации и план профессиональной пробы. Она доступна без внешнего ИИ; её можно скачать текстом или распечатать в PDF.

Дополнительный ИИ-разбор появляется только при заданном VITE_GOOGLE_SCRIPT_URL из .env.example. Пользователь запускает запрос явно. Сервер должен принять POST text/plain с JSON { action: "generate_ai", prompt: "..." } и вернуть JSON { text: "..." }. Все секреты, доступ к провайдеру, CORS, ограничения запросов и правила обработки данных остаются на сервере. Реальный сервер и провайдер в репозитории не настроены и не проверены. Ошибка или тайм-аут не подменяются готовым «ИИ-выводом».
