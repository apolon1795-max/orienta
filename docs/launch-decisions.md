# Решения перед запуском

Текущая ветка поддерживает автономное прохождение и вход по личному коду с серверным сохранением. Для российского пилота созданы YDB Serverless, две серверные функции и API Gateway. Публичный API прошёл проверку сохранения, конфликта, изоляции и восстановления прогресса; подключение существующего сайта Timeweb фиксируется в PR. Реальные ссылки на уроки ещё ожидаются.

| Вопрос | Текущее состояние | Нужное решение |
| --- | --- | --- |
| Видео пяти этапов | Даниил выбрал Kinescope; плеер и сохранение позиции подготовлены | Даниил предоставляет ссылки и соответствие пяти этапам; затем проверить реальные ролики |
| Учётные записи и база | Личные коды, серверный API, версии, восстановление, экспорт и локальные проверки готовы | Подтвердить создание/подключение ресурсов Яндекс Cloud; проверить реальное YDB и переход между устройствами |
| ИИ | Профкарта работает без ИИ; есть клиентский адаптер дополнительного разбора | Выбрать провайдера, сервер и правила обработки ответов, если ИИ нужен при старте |
| Методика и возраст | Аудитория подтверждена: только школьники в России. Программа — пять этапов по историческим страницам Notion | Подтвердить окончательную редакцию и точный возрастной диапазон; провести содержательную проверку экспертом |
| Гайды | Сохранены четыре исходных гайда; убран неверный счётчик «Топ-15» | Согласовать содержание и формулировки рекомендаций |
| Контакты | Взяты исходные ссылки на наставника и сообщество | Подтвердить актуальность и назначение этих ссылок |
| Иллюстрации и шрифты | Кешируются исходные PNG; шрифты пока Google Fonts с системными заменами | Подтвердить право использования и требования к внешним шрифтам |
| Открытие уроков | Следующий доступен после выполнения предыдущего, без ограничения по датам | Подтвердить этот вариант или задать недельное расписание |
| Площадка | Найден существующий бесплатный фронтенд Orienta в Timeweb; базы в аккаунте Timeweb нет | Оставить этот фронтенд и подключить серверное сохранение Яндекса; согласовать тарифицируемые ресурсы перед созданием |

Игровой результат не является валидированной психометрической методикой. Четыре архетипа и самооценка служат отправной точкой для профессиональных проб; текст интерфейса больше не обещает определить пригодность. При равенстве баллов показаны все лидирующие архетипы; основной персонаж выбран по исходному порядку.

Платежи, административный веб-кабинет, управление группами и проверка заданий педагогом не реализованы. Для пилота есть административный CLI и закрытая функция выдачи кодов и выгрузки результатов. Серверная синхронизация проверена с настоящими SQLite и российской YDB через публичный API. Проверка реальных видео состоится после получения ссылок. SQLite не предназначена для диска контейнера App Platform или Cloud Functions.
