# Решения перед запуском

Техническая основа текущей ветки — автономное прохождение в браузере. Это рабочее допущение для завершения сценариев, а не согласованная модель публичного запуска.

| Вопрос | Текущее состояние | Нужное решение |
| --- | --- | --- |
| Видео пяти этапов | Текстовые инструкции и подключение реальных видео/субтитров через конфигурацию | Подтвердить запуск с текстом или предоставить ролики |
| Учётные записи и база | Локальное сохранение, экспорт/импорт резервной копии | Достаточно для первого запуска или нужны кабинеты/Telegram и общая база |
| ИИ | Профкарта работает без ИИ; есть клиентский адаптер дополнительного разбора | Выбрать провайдера, сервер и правила обработки ответов, если ИИ нужен при старте |
| Методика и возраст | Входная игра и подробные задания пяти этапов Notion; возраст ограничен 6–100 для проверки ввода | Подтвердить найденную редакцию и аудиторию; провести содержательную проверку экспертом |
| Гайды | Сохранены четыре исходных гайда; убран неверный счётчик «Топ-15» | Согласовать содержание и формулировки рекомендаций |
| Контакты | Взяты исходные ссылки на наставника и сообщество | Подтвердить актуальность и назначение этих ссылок |
| Иллюстрации и шрифты | Кешируются исходные PNG; шрифты пока Google Fonts с системными заменами | Подтвердить право использования и требования к внешним шрифтам |
| Открытие уроков | Следующий доступен после выполнения предыдущего, без ограничения по датам | Подтвердить этот вариант или задать недельное расписание |
| Площадка | Сборка статическая; ничего не развёрнуто | Даниил определяет хостинг и место подключения |

Игровой результат не является валидированной психометрической методикой. Четыре архетипа и самооценка служат отправной точкой для профессиональных проб; текст интерфейса больше не обещает определить пригодность. При равенстве баллов показаны все лидирующие архетипы; основной персонаж выбран по исходному порядку.

Не входят в текущую автономную версию: платежи, административный кабинет, управление группами, проверка заданий педагогом, подтверждённая серверная синхронизация. Эти функции не подтверждены источниками как обязательные требования.

Полного алгоритма сочетания типа, мотивации и профессий в источнике нет. Гипотезы берутся из выбора участника, а примеры из описаний типов служат запасным вариантом. Мотиваторы используются как критерии проверки реальной работы; скрытый балл пригодности не выдумывается.
